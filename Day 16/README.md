# E-Commerce Order Prediction API
## Project Overview
This project is developed as part of the **ProSensia AI & ML Internship – Day 16**.
The objective of this project is to deploy a Machine Learning model using **FastAPI** and improve the API by implementing **Pydantic Data Validation**. # Input Validation

The API uses **Pydantic BaseModel** for request validation.

Benefits include:

- Automatic datatype validation
- Required field checking
- Invalid input protection
- Automatic HTTP 422 response for invalid requests
# Why Data Validation is Important
Machine Learning models expect data in a specific format.
Incorrect or missing values can produce incorrect predictions or even crash the application.
Using **Pydantic** ensures that only valid and properly formatted data reaches the Machine Learning model.
# Garbage In, Garbage Out (GIGO)
Garbage In, Garbage Out (GIGO) is a fundamental concept in Machine Learning.

It means that if invalid, incomplete, or poor-quality data is provided to a Machine Learning model, the predictions will also be unreliable.

Pydantic helps prevent this problem by validating incoming requests before they reach the model.
