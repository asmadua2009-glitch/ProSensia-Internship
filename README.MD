# AI/ML Engineering Squad - Day 3

## Project Title
Statistical Outlier Detection using Z-Score and IQR

## Objective
The objective of this project is to detect and handle statistical outliers using Z-Score and IQR methods with vectorized Pandas and NumPy operations.
## Technologies Used
- Python
- Pandas
- NumPy
- SciPy
- Jupyter Notebook

## Project Files
- Day_3_Outlier_Detection.ipynb
- features_v1.csv
- final_clean_v2.csv
- README.md

## Workflow
1. Load the dataset.
2. Check dataset information.
3. Detect outliers using the Z-Score method.
4. Remove outliers using the IQR method.
5. Export the cleaned dataset as `final_clean_v2.csv`.

## Output
The final cleaned dataset is saved as:

`final_clean_v2.csv`
