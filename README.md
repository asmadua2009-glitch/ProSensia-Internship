# Loan Default Classification - Weekend Project
## Project Overview
This project focuses on building an end-to-end machine learning classification pipeline to predict loan default-related outcomes. The workflow includes data preprocessing, handling class imbalance, model training, evaluation, and model comparison.
## Dataset
The project uses the cleaned and preprocessed dataset provided during the internship.
## Models Used
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
## Techniques Applied
- Data Cleaning
- One-Hot Encoding
- Train-Test Split
- SMOTE (Training Data Only)
- Model Evaluation
- ROC-AUC Curve Comparison
## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC
## Best Model
Random Forest achieved the highest overall performance with an accuracy of **61.1%** and the best weighted F1-score.
## Conclusion
This project demonstrates the importance of preventing data leakage, handling class imbalance correctly, and evaluating models using multiple metrics instead of relying only on accuracy.
