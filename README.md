# Day 1 - Data Cleaning Project

## Objective
The objective of this project is to clean the Titanic dataset using Pandas and NumPy.

## Tasks Performed
- Loaded the dataset
- Checked missing values
- Filled missing values
- Removed outliers using the IQR method
- Used Pandas vectorized operations
- Saved the cleaned dataset
