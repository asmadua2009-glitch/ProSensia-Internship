# Global E-Commerce Sales - Exploratory Data Analysis (EDA)

## Project Description

This project is part of the AI & ML Engineering Internship Weekend Project.

The objective of this project is to clean the Global E-Commerce Sales dataset, perform Exploratory Data Analysis (EDA), create meaningful visualizations, and generate business insights.

## Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow

- Imported the dataset
- Cleaned missing values
- Removed duplicate records
- Performed Exploratory Data Analysis (EDA)
- Created visualizations
- Generated business insights
- Exported the cleaned dataset

## Visualizations

- Correlation Heatmap
- Revenue Distribution
- Revenue by Category
- Revenue by Region
- Profit by Customer Segment
- Shipping Cost Analysis
- Order Status Distribution

## Business Insights

- Revenue and Cost have a strong positive correlation.
- Electronics generated the highest average revenue.
- Middle East generated the highest average revenue.
- New customers showed the highest average profit.
- Overnight shipping had the highest average shipping cost.
